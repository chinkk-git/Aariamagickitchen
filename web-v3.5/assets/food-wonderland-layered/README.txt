AARIA FOOD WONDERLAND — LAYERED ASSET HANDOFF

READY TO PLACE: 2 full-screen scenic backgrounds + 18 separate transparent PNG assets + positioning manifest + optional CSS/JS renderer.

IMPORTANT VISUAL FIDELITY NOTE:
These sprites and backgrounds are newly recreated to match the approved aesthetic; they are NOT pixel-exact cutouts of the currently deployed artwork. Do not overwrite the approved production backgrounds without owner comparison/approval. This package is a usable separated-layer prototype/handoff.

All sprites are independently placed, with recommended positions in manifest.json for portrait and landscape. Each icon and wooden sign has its own PNG and click region. No icons are baked into the supplied backgrounds.

HOW TO USE:
1. Unzip into an isolated web-v3.5 asset folder.
2. Load manifest.json; choose portrait or landscape positions.
3. Place background as cover; place sprite PNGs using percentage positions.
4. Connect each sprite and sign to existing app routes using routes map; no new navigation routes.
5. For exact globe parity, REUSE the existing v34-hero-globe animation and globe artwork instead of this placeholder globe PNG.
6. Retain the existing wheel spin handler and sound effects; use the wheel sprite as the visual layer.
7. Verify fit/positions on real portrait and landscape screens; adapt sizes to current UI safe areas.
8. Do not publish until owner approves new art fidelity.

Aaria/kitten are independent static cutouts. Blinking/limb animation requires additional rigged art, not provided.

Files: backgrounds/{portrait,landscape}.webp; sprites/*.png; manifest.json; integration/layers.{css,js}.
