# Offline country boundaries used by the V3.1 world explorer

`ne_110m_admin_0_countries.geojson` is Natural Earth Vector Admin 0 Countries, 1:110m, sourced from:

- https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- Dataset information: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- Terms: https://www.naturalearthdata.com/about/terms-of-use/

Natural Earth states its vector and raster data are public domain. The file is bundled for offline rendering; the application does not call a map tile service. The 1:110m scale is a small-scale world overview and is not suitable for navigation or legal boundary decisions. The map presents the dataset's de facto country boundaries and may reflect disputed or simplified boundaries.
