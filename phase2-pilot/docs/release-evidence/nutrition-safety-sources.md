# Nutrition and food safety source plan

## Nutrition

Use USDA FoodData Central as the traceable starting point for generic unbranded ingredients: <https://fdc.nal.usda.gov/>. The official FDC API documentation explains food lookup and data access: <https://fdc.nal.usda.gov/api-guide/>. The pilot currently has not selected exact branded granola, bread, pizza sauce or cheese records, and it does not yet expose numeric nutrient totals. Values must be mapped ingredient by ingredient, scaled to the recipe quantity, summed per serving, independently recalculated and dated by a qualified reviewer before release.

For each ingredient, retain source database/type, FDC ID, description, retrieval date, nutrient values and calculation. For substitutions, recompute from traceable data; otherwise label that custom version unverified. FDC is a data source, not a substitute for clinical or allergy advice.

## Food safety and adult help

- FoodSafety.gov's four-step guidance covers clean, separate, cook and chill: <https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety>.
- The American Academy of Pediatrics' family food-safety guidance discusses burn prevention, adult supervision and safe handling: <https://www.healthychildren.
