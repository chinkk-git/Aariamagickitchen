# V3.5 executable release validation package

The harness is QA-only: `tools/v3/qa/v35-upgrade-validation.mjs`. It fetches the current production HTML, serves production then the checked-out V3.5 candidate through one local origin, seeds synthetic records using the app's existing localStorage keys and a dedicated test IndexedDB, upgrades by changing the same-origin response without clearing browser storage, and writes JSON diagnostics plus screenshots on failures. It does not rebuild or alter application code.

## Exact Codespaces command

Run from the repository root in the existing Codespace. Node 20+ and npm are required. Playwright and generated evidence are installed under `/tmp` so the checkout stays clean.

```bash
test "$(git branch --show-current)" = "release/v3.5-html-recovery-20261030" && git merge-base --is-ancestor c10d56e27ea27e60dd02c804ea95cb9a3b7e1e75 HEAD && npm install --prefix /tmp/aaria-v35-qa playwright && node /tmp/aaria-v35-qa/node_modules/playwright/cli.js install chromium webkit && NODE_PATH=/tmp/aaria-v35-qa/node_modules AARIA_CANDIDATE_ROOT="$PWD" AARIA_QA_REPORT=/tmp/aaria-v35-upgrade-report.json node tools/v3/qa/v35-upgrade-validation.mjs
```

The report is `/tmp/aaria-v35-upgrade-report.json`; failures also write a per-engine PNG alongside it. Review the independent approvals required in `docs/v3.5-release-independent-review-checklist.md`.

Chromium and desktop WebKit are simulations. They are not evidence of physical Android Chrome/WebView, iOS Safari, or WKWebView testing. The script does not self-approve independent safety, accessibility, security, nutrition/allergen, or artwork-rights gates.
